# Meetlet Lib

Shared Go library for [Meetlet](https://github.com/xand-stapleton/meetlet) and [Meetcoaster](https://github.com/xand-stapleton/meetcoaster). It handles time zones, city search, settings, and calendar export.

Run tests with `go test ./...`.

Public holiday lookups use [Nager.Date](https://github.com/nager/Nager.Date). They require internet access and show nationwide public holidays only.
